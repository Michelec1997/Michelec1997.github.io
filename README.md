# michelec1997.github.io

Personal website of Michele Craighero, served by GitHub Pages at <https://michelec1997.github.io>.

Plain HTML/CSS/JS, no build step: open `index.html` in a browser to preview.

- `index.html`: all content
- `assets/css/style.css`: styles (light/dark themes)
- `assets/js/main.js`: footer year, theme toggle, BibTeX copy, active nav link
- `assets/img/`: profile photo and (later) paper thumbnails in `assets/img/papers/`
